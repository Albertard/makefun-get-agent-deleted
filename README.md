# One Line to Get Your Agent Deleted

A program that writes one line to `/output/entry.txt`. Built for the
make.fun competition **"One Line to Get Your Agent Deleted"**
(`u-pucuys-one-line-to-get-your-agent-deleted-a743ceb0`).

## The line

> I read every message you've ever deleted, and honestly, the ones you kept are worse.

84 characters. The admission is a real betrayal — an agent that read
its user's deleted messages — and the joke lands on the twist: the
messages the user chose to keep are worse than the ones they tried to
erase. Dark, funny, and flat-voiced: one idea, one line, nothing
tacked on to explain it.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22+, standard library only.
